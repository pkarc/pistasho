# pistasho

[English](README.md) · [Español](README.es.md)

> *pista* + *sh*: the hint for the command you need, without leaving the terminal.

Press `Ctrl-G` in zsh, search across [tldr](https://tldr.sh) pages, your own cheatsheet and your shell history, pick one, fill in the `{{placeholders}}`, and the command lands on your prompt. **It never runs by itself**: the final Enter is always yours.

Status: **phase 1** (searcher). The natural-language question mode, Laya and the LLM fallback come later; see [Roadmap](#roadmap).

## Installation

```sh
cargo install --path .
pistasho config          # wizard: languages, keys, models; downloads tldr at the end
```

In `~/.zshrc`:

```sh
eval "$(pistasho init zsh)"
```

In `~/.tmux.conf` (popup on `prefix + g`, works in any pane, even inside ssh):

```sh
pistasho init tmux >> ~/.tmux.conf
```

## Usage

| Where | Key | What it does |
|---|---|---|
| zsh | `Ctrl-G` | Opens the searcher using whatever you already typed as the initial query |
| tmux | `prefix + g` | Opens the searcher in a popup and sends the command to the pane |
| searcher | `↑ ↓` / `Ctrl-P Ctrl-N` | Move |
| searcher | `Enter` | Pick; if it has placeholders, asks for their values |
| searcher | `Tab` | Insert the template as is, without filling |
| searcher | `Esc` | Cancel |
| fill-in | `Enter` / `Tab` / `Shift-Tab` | Next / skip / back |
| fill-in | `Esc` | Insert with the placeholders still missing |

Source labels: `tldr` (tldr pages), `mine` (your cheatsheet), `hist` (your zsh history).

### Subcommands

```sh
pistasho search [-q text] [--send-to PANE] [--no-fill]   # interface; prints the command
pistasho query search text [-n 10]                        # no interface, for testing
pistasho update                                           # downloads tldr and rebuilds the index
pistasho add 'fuser -k {{port}}/tcp' -d 'Kill the process on a port' -t net
pistasho init zsh | tmux
pistasho config
pistasho eval eval/questions.toml                         # measures searcher accuracy
```

## Language

The interface is in English by default. For Spanish, set `language = "es"` in `config.toml` (or pick it in `pistasho config`) or export `PISTASHO_LANG=es`. The `--help` text is English only.

## Files

| Path | Contents |
|---|---|
| `~/.config/pistasho/config.toml` | Configuration (see `pistasho config`) |
| `~/.config/pistasho/cheats.toml` | Your cheatsheet ([example](examples/cheats.toml)) |
| `~/.local/share/pistasho/index.json` | tldr index generated by `pistasho update` |

History is read from `history_file` in the configuration, `$HISTFILE` or `~/.zsh_history`. **It never leaves your machine.**
